# Operation ID + PostgreSQL

Кнопки в окне расширения:

- **Скопировать** — собрать `operation_id` со страницы и записать SQL-список в буфер.
- **Проверить в БД** — выполнить SELECT и открыть результат в отдельной вкладке.
- **Подключение** — открыть поле для ключа локального сервиса.

Если на этой вкладке уже нажимали «Скопировать», в БД отправляются именно последние скопированные ID. Если ещё не копировали, ID собираются с текущей страницы. Расширение не читает системный буфер обмена.

## Первый запуск на Mac

1. В `chrome://extensions` обнови расширение или загрузи эту папку как распакованное расширение. Подтверди разрешения, если Chrome запросит. Для установленного расширения на рабочем столе путь остаётся прежним.
2. Открой **Параметры** расширения через меню Chrome. На странице **Подключение к БД** скопируй ID расширения.
3. Дважды нажми **Настроить БД.command** в этой папке. Введи логин и пароль БД, схему `report_stock`, режим SSL как в текущем подключении DataGrip и ID расширения. Пароль вводится скрыто. Если SSL не используется — выбери `disable`. Если используется — `verify-full` и, при необходимости, путь к корневому сертификату.
4. Настройка выдаст ключ локального сервиса. Вставь его в **Подключение к БД** и нажми **Сохранить**.
5. Включи VPN и запусти **Запустить БД.command**. При первом запуске он установит драйвер `pg` из npm. После сообщения об успешном запуске окно Terminal можно закрыть: сервис работает в фоне.
6. Открой обращение → значок расширения → **Проверить в БД**.

Нужны Node.js 22+ с npm и Python 3. На подготовленном компьютере они уже обнаружены. Для остановки сервиса запусти **Остановить БД.command**. Повторный запуск выполняется через **Запустить БД.command**. После выхода из пользовательского сеанса или перезагрузки Mac запусти эту команду ещё раз. Скрипт настройки можно запустить повторно, чтобы изменить логин, пароль, схему или SSL.

Ключ локального сервиса — отдельный случайный ключ. Это не пароль PostgreSQL. Если меняется ID расширения, обнови его в настройке сервиса и перезапусти сервис.

## Запрос

Выполняется только этот фиксированный SELECT, с переданными параметрами вместо подстановки текста ID:

```sql
select operation_id, location_id, address_id, product_id,
       quantity_delta, operation_type, motive, reference, operation_date
from report_stock rs
where operation_id in ($1, $2, ...)
```

Имя схемы задаётся при настройке. Параметры позволяют работать с `operation_id` как типа `uuid`, так и строкового типа, без приведения самого столбца. Поддерживается до 2000 ID за запрос; повторы удаляются.

Запрос выполняется в транзакции `READ ONLY`, с лимитом выполнения 15 секунд. Сервис возвращает до 10 000 строк, а превышение явно отмечается в результате. Строки отображаются страницами по 200. При ограниченном результате список отсутствующих ID не вычисляется. Числовые значения высокой точности и даты не округляются и не переводятся в локальный часовой пояс браузера.

Таблица показывает все девять столбцов и номера строк слева. Нумерация сквозная: на второй странице начинается с 201. ID без найденных строк выводятся отдельно. Пункт **SQL и отправленные ID** показывает список, который был отправлен. Кнопка **Повторить запрос** использует тот же набор ID.

## Как устроено подключение

Расширение отправляет ID локальному сервису `http://127.0.0.1:17879`. Сервис на этом компьютере подключается к PostgreSQL через VPN и возвращает строки. Браузер не хранит логин и пароль БД.

Сервис принимает запросы только с ID настроенного расширения и правильным ключом; слушает только `127.0.0.1`. Произвольный SQL выполнить через API нельзя. Пароль, ID и результаты не пишутся в журнал. При закрытии браузера списки ID удаляются из сессионного хранилища. Ключ сервиса сохраняется локально в браузере, без синхронизации.

Параметры БД хранятся в `~/Library/Application Support/Operation ID/bridge/.local/config.json` с правами доступа только для текущего пользователя, отдельно от исходников. Фоновый сервис запускается через macOS launchd, без постоянно открытого Terminal. При успешном завершении настройки сервис автоматически запускается или перезапускается. Его журнал находится рядом с настройками, в `service.log`. Файл настроек содержит пароль после локальной настройки. При первом запуске старый локальный профиль переносится в пользовательскую папку macOS. Папка `.local/` и `node_modules/` исключены через `.gitignore` и не входят в архив исходников. При ручной загрузке в GitHub их тоже не загружай.

Для сборки и использования расширения npm не требуется. npm нужен только локальному сервису. В GitHub можно загрузить все исходники, включая `bridge/package-lock.json`; зависимости устанавливаются через `cd bridge && npm ci --ignore-scripts`.

## Копирование без БД

Для кнопки **Скопировать** сервис, VPN и настройки БД не нужны. Формат:

```sql
(
    '40ecba4d-05e3-44dc-a65b-2dcebbe2477d',
    '6280f368-ef7d-4799-9502-a2c601a3b777',
    '144cb756-a96d-49ed-b75a-30c5fccd9573'
)
```

Сбор поддерживает `operation_id`, `operation id`, `operationId`, JSON, переносы UUID, редакторы, поля ввода, открытый Shadow DOM и доступные встроенные страницы того же источника. Скрытые заметки нужно сначала раскрыть. Если часть встроенных блоков недоступна, кнопка предупреждает при наведении; проверка в БД требует открыть такой блок отдельной вкладкой.

Если ID не найдены, буфер остаётся прежним. Для работы с сохранёнными HTML-файлами включи **Разрешить доступ к URL файлов** у этого расширения.

## Проверка разработки

```sh
cd bridge
npm ci --ignore-scripts
npm test
```

API проверяет ID, источник запроса, ключ и параметры. В тестах проверяются параметризация, запрет произвольного SQL, `READ ONLY`, ограничения результата, откат транзакции и обработка ошибок.

Технические источники: [параметризованные запросы node-postgres](https://node-postgres.com/features/queries), [режим READ ONLY PostgreSQL](https://www.postgresql.org/docs/current/sql-set-transaction.html), [сетевые запросы расширений Chrome](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests).

Фоновый запуск использует [стандартный механизм macOS launchd](https://support.apple.com/guide/terminal/script-management-with-launchd-apdc6c1077b-5d5d-4d35-9c19-60f2397b2369/mac). Автозапуск при входе в macOS не устанавливается.
